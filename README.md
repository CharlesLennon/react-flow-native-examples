# React Flow Native Examples

Public `.rfn` (React Flow Native) flow definitions and embedded process logic for [React Flow Native](https://github.com/CharlesLennon/biodiesel-flow).

## Structure
- `manifest.json`: Index of available `.rfn` example flows synced by the app.
- `flows/biodiesel.rfn`: Gravity-fed 3-tier biodiesel processor with a dual-input methoxide dosing pump (heated dry oil + methoxide catalyst) and embedded stoichiometry/temperature interlock logic.
